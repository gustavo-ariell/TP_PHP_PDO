2. Descripción breve del problema

El presente sistema tiene como objetivo gestionar la operación de una biblioteca escolar, permitiendo administrar libros, autores, editoriales, estudiantes y préstamos.

La aplicación web permite registrar libros y autores, asociar los libros con sus respectivas editoriales, registrar estudiantes de la institución y gestionar los préstamos de libros, incluyendo:

  • Registrar libros, autores, estudiantes y préstamos.
  • Consultar libros disponibles y libros prestados.
  • Consultar préstamos realizados por estudiante.
  • Modificar información de libros.
  • Registrar devoluciones.

El sistema fue desarrollado como prototipo funcional utilizando HTML5, CSS3, PHP con PDO y MySQL, integrado con la base de datos relacional diseñada en el trabajo práctico anterior mediante MySQL Workbench.

$sql = "SELECT l.id_libro, l.titulo, l.isbn, l.anio,
               e.nombre AS editorial, l.ejemplares
        FROM libro l
        LEFT JOIN editorial e ON l.id_editorial = e.id_editorial
        ORDER BY l.titulo";

$stmt = $pdo->query($sql);
$libros = $stmt->fetchAll();

12. Captura de una consulta utilizando INNER JOIN

[ Captura de la consulta "Préstamos por estudiante"
mostrando tabla HTML con datos combinados de
estudiante, libro y préstamo ]

12.1. Sentencia SQL utilizada

$sql = "SELECT
            e.nombre,
            e.apellido,
            e.dni,
            l.titulo,
            l.isbn,
            p.fecha_prestamo,
            p.fecha_devolucion,
            p.estado
        FROM prestamo p
        INNER JOIN estudiante e ON p.id_estudiante = e.id_estudiante
        INNER JOIN libro l ON p.id_libro = l.id_libro
        WHERE p.id_estudiante = :id_estudiante
        ORDER BY p.fecha_prestamo DESC";

$stmt = $pdo->prepare($sql);

$stmt->execute([
    ':id_estudiante' => $id_estudiante
]);

$prestamos = $stmt->fetchAll();

14. Explicación del funcionamiento general de la aplicación

14.1. Conexión a la base de datos

La aplicación utiliza un archivo independiente conexion.php que establece la conexión a MySQL mediante la clase PDO. Este archivo es reutilizado por todas las páginas mediante require_once.

14.2. Operaciones CRUD

  • CREATE: Formularios HTML que envían datos mediante $_POST y ejecutan sentencias INSERT INTO mediante prepare() y execute().
  • READ: Páginas de listado que ejecutan SELECT y muestran los resultados en tablas HTML.
  • UPDATE: Formularios de edición con datos precargados que ejecutan UPDATE ... SET ... WHERE.
  • DELETE: Páginas de confirmación que ejecutan DELETE FROM ... WHERE.

14.3. Relaciones entre tablas

Los formularios que requieren referencias a otras tablas utilizan elementos <select> dinámicos, donde las opciones se obtienen mediante consultas SELECT a la base de datos. El usuario visualiza el nombre descriptivo, pero la aplicación almacena la clave foránea correspondiente.

14.4. Consultas relacionadas

El sistema incluye consultas que utilizan INNER JOIN para combinar información de múltiples tablas:

  • Préstamos por estudiante (estudiante + libro + préstamo).
  • Libros con sus autores (libro + libro_autor + autor).
  • Libros disponibles.

14.5. Validaciones

Los formularios incorporan validaciones HTML (required, type="email", type="number", type="date") y validaciones desde PHP mediante verificación de campos vacíos y uso de try / catch para capturar errores de la base de datos.

14.6. Mensajes de estado

Cada operación (alta, modificación, eliminación) muestra un mensaje de estado indicando si la operación fue realizada correctamente o si ocurrió un error.
